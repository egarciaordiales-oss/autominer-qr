# AUT-002 · Sitio completo para GitHub Pages

Punto AUTOMINER dedicado a las columnas y elementos de hormigón armado de la Escuela Politécnica de Mieres.

## Contenido incluido
- `index.html` — página principal.
- `recursos-minerales.html` — materias primas y mineralogía.
- `cadena-valor.html` — de la extracción a la puesta en obra.
- `propiedades.html` — comportamiento estructural y durabilidad.
- `sostenibilidad.html` — impacto, circularidad y fin de vida.
- `infografia.html` — página de la infografía.
- `ficha-tecnica.html` — ficha universitaria resumida.
- `quiz.html` — autoevaluación interactiva con 8 preguntas.
- `bibliografia.html` — fuentes técnicas y normativa.
- `assets/` — estilos, JavaScript, fotografía e infografía.
